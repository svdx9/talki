# Talki

Real-time language learning platform with AI conversation partners.

## Structure

- `backend/` - Hono API server
- `frontend/` - SolidJS + Vite client
- `shared/` - Common types and protocols

## Setup

```bash
pnpm install
pnpm dev
```

## Development

- Backend runs on `:8787`
- Frontend dev server proxies API requests to backend
